About NovaChat

Welcome to NovaChat! NovaChat is a proof-of-concept instance of the LetsChat project.

LetsChat is an innovative software that allows developers to self-host internet forums with ease.

NovaChat serves as a demonstration of what can be achieved with LetsChat.

Source Code

Both LetsChat and NovaChat are licensed under the GNU Affero General Public License Version 3 (or the GNU AGPLV3 for short).

Both the LetsChat source code and the NovaChat source code are publicly available on GitHub.

Note that the NovaChat source code comes with a heavily modified build of the original LetsChat source code and is barely identical to upstream.

Other Projects

This section highlights some more notable LetsChat projects.

LetsChat Extended is a repository that holds Extended support releases of LetsChat, more information can be found here.

The LetsChat Plugin Store is currently still in it's early stages but is on track to become a well-maintained store.

Kwitter is the base for LetsChat while also being the specification for LetsChat, it's architecture and it's plugins.

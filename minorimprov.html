Full List of Improvements

PWA support has been added to NovaChat, the plan is to have this feature be upstreamed so that other instances can easily be made into PWAs.

NovaChat Labs is a new part of NovaChat that will be a platform within NovaChat for experimental LetsChat technologies that may or may not eventually be a part of NovaChat or even upstream LetsChat. It is built off of the External Services component from LetsChat Social since it functioned in a similar way to what Labs needed.

The login form in index.html has been centred.

The navbar entries have been rearranged to have the about page be the last entry.

The update policy for legacy LetsChat Social components has been revisited, they are still officially unsupported but are still getting some updates like updated navbar entries for example.

The upcoming features tab has been removed as it was never updated with any upcoming changes and is not really suitable for how modern NovaChat development takes place.
